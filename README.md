# 🎁 선물 던지기 대작전 3D

눈 내리는 크리스마스이브 광장에서 산타와 엘프가 선물 상자를 던지며 겨루는 3D 대전 게임입니다.
설치할 것 없이 HTML 파일 하나로 브라우저에서 바로 실행됩니다.

### ▶️ [바로 플레이하기](https://pjt3591oo.github.io/mini-2026-x-mas-game/)

https://pjt3591oo.github.io/mini-2026-x-mas-game/

## 실행 방법

- 위 링크로 접속하면 바로 플레이할 수 있습니다.
- 로컬에서 실행하려면 `index.html`을 브라우저(Chrome, Edge, Safari, Firefox)로 열면 됩니다.
- 3D 엔진인 [three.js](https://threejs.org/)(r160)를 CDN에서 불러오기 때문에 **인터넷 연결이 필요합니다.**
- 로컬 서버로 띄우고 싶다면:
  ```bash
  python3 -m http.server 8000
  # http://localhost:8000 접속
  ```

## 게임 규칙

- 나는 **산타**, 상대는 **엘프(CPU)** 입니다. 중앙의 사탕 막대 선을 사이에 두고 각자 자기 진영에서만 움직일 수 있어요.
- 선물에 맞으면 하트가 하나 줄고, 하트 5개를 먼저 모두 잃으면 라운드 패배입니다.
- **2라운드를 먼저 이기면 승리.** 라운드 시간은 60초이고, 시간이 다 되면 하트가 더 많은 쪽이 이깁니다.
- 날아가는 선물끼리 공중에서 부딪히면 둘 다 터집니다. 날아오는 선물을 맞받아쳐 막을 수 있어요.
- 진영마다 **눈벽**이 3개씩 있어 뒤에 숨을 수 있습니다. 선물에 맞을수록 낮아지다가 무너져요.
- CPU 난이도는 **쉬움 / 보통 / 어려움** 세 가지입니다.

## 조작법

| 동작 | 키보드·마우스 | 모바일 |
| --- | --- | --- |
| 시점·던질 방향 회전 | 마우스 좌우 (또는 `Q` / `E`) | 화면 드래그 (좌우) |
| 낙하 지점 거리 조절 | 마우스 앞뒤 (또는 `R` / `F`) | 화면 드래그 (위아래) |
| 던지기 | 마우스 클릭 또는 `J` | 던지기 버튼 |
| 이동 | `W` `A` `S` `D` / 방향키 (카메라 기준) | 가상 조이스틱 |
| 점프 | `스페이스` | 점프 버튼 |
| 일시정지 | `P` | — |
| 음소거 | `M` | — |
| 마우스 풀기 → 메뉴 | `Esc` (한 번: 일시정지, 두 번: 메뉴) | — |

- 게임 화면을 클릭하면 마우스 커서가 고정되어(포인터 락) 시점을 조작할 수 있습니다.
- 바닥의 **노란 링**이 선물이 떨어질 곳입니다. 링이 엘프 위에 올라가면 **빨갛게** 바뀝니다.
- 던진 뒤 0.5초가 지나야 다시 던질 수 있고, 그동안 궤적 점선이 흐려집니다.

## 아이템

하늘에서 낙하산에 매달린 아이템이 양쪽 진영에 번갈아 떨어집니다. 가까이 가면 획득해요.

| 아이템 | 효과 |
| --- | --- |
| 🎁 왕선물 | 다음 3번 던질 때 큰 선물(피해 2) |
| 🎁🎁🎁 세 갈래 | 다음 3번 던질 때 한 번에 3개씩 부채꼴로 |
| ❤️ 체력 | 하트 1개 회복 |
| ❄️ 눈꽃 방패 | 10초 동안 한 번 맞는 것을 막아 줌 |

## 기술 메모

- 단일 파일(`index.html`): HTML + CSS + JavaScript(ES 모듈), 빌드 과정 없음
- 렌더링: three.js r160 (CDN `cdn.jsdelivr.net`), 그림자, 안개, 파티클
- 효과음: Web Audio API로 직접 합성 (외부 음원 없음)
- 메뉴 화면 뒤에서는 CPU끼리 싸우는 데모가 자동으로 진행됩니다.
